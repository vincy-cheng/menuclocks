# DEVOPS

Swift Package Manager project (`Package.swift`, swift-tools-version 6.0, macOS 13+). Requires Xcode with Swift 6 or newer. No external dependencies.

## Commands

| Command | What it does |
| --- | --- |
| `./scripts/build.sh` | Release build, assembles `dist/MenuClocks.app` (Info.plist, icon), ad-hoc signs it |
| `swift test` | Runs the `ClockCoreTests` test target |
| `open dist/MenuClocks.app` | Launches the built app |

## Setup

Nothing beyond Xcode. `scripts/build.sh` sets a local module cache under `.build/` to keep builds hermetic; run it from the repo root (the script computes the root itself).

## Notes

- The app is ad-hoc signed (`codesign --force --sign -`), not notarized — fine for local use and Application-folder installs, not for wide distribution.
- Distribution artifact is `dist/MenuClocks.app`; it can run from any folder.
- Build outputs `.build/` and `dist/` are not tracked; `docs/features/` and `.dev-flow/` are gitignored.
