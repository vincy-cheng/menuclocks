# ARCHITECTURE

macOS menu bar world clock (SwiftUI + AppKit, no external dependencies, no network access). Swift targets defined in `Package.swift`:

| Target | Role | Files |
| --- | --- | --- |
| `ClockCore` | Time-zone logic, no UI | `Sources/ClockCore/Clock.swift` |
| `MenuClocks` | Executable: UI + app lifecycle | `Sources/MenuClocks/main.swift` |
| `ClockCoreTests` | Clock formatting and JSON compatibility tests | `Tests/ClockCoreTests/ClockTests.swift` |
| `MenuClocksTests` | Monitor lifecycle and Quit menu tests | `Tests/MenuClocksTests/PopoverDismissalTests.swift` |

## ClockCore (`Clock.swift`)

Single `Clock` struct (Codable, Sendable): one time zone (`id`), optional custom `label`, `pinned` flag, `menuBarNameMode`, and `shortName`. Existing JSON without the new fields decodes with full-name defaults. All formatting/comparison logic lives here so it is testable:

- `time(at:use24Hour:)` / `dateText(at:)` — per-zone formatting via `DateFormatter` with a fixed POSIX locale for time.
- `dayDifference(at:relativeTo:)` — calendar-day delta vs the Mac's zone (DST and date-line safe).
- `offset(at:)` — UTC offset string, including fractional offsets (e.g. `UTC+5:45`).
- `abbreviation(at:)` — regional English short names provide HKT/JST for Hong Kong/Japan; other zones use date-sensitive system abbreviations. Shared by the list and menu bar.
- `menuBarName(at:)` — full name, date-sensitive system time zone abbreviation, or trimmed custom short name with full-name fallback.
- `menuBarEntries(clocks:at:use24Hour:)` — shared name/time pairs for the first two pinned clocks, with names capped at 14 characters.
- `menuBarTitle(clocks:at:use24Hour:)` — single-line title using those pairs, then `+N` overflow.
- `search(_:)` — filter over `TimeZone.knownTimeZoneIdentifiers`, normalizing `_` to spaces.

## MenuClocks (`main.swift`)

Three pieces, in one file:

1. `ClockStore: ObservableObject` — app state. Holds `clocks`, `use24Hour`, `twoLineMenuBar`, live `now`, and `previewHours` (look-ahead/behind slider, ±24h in 0.5h steps → `viewedDate`). Persists `clocks` (JSON) and `use24Hour` / `twoLineMenuBar` to `UserDefaults.standard` (bundle id `local.menuclocks.app`). Refreshes `now` every 5 s while the Mac is awake. Loads saved clocks but filters out unknown/invalid zone ids.
2. `ClockPanel: View` — the popover UI (390×580): clock list (with Edit mode for label/reorder/remove/pin), search panel to add zones from `Clock.search`, look-ahead timeline, footer (24-hour toggle, copy, two-line menu bar toggle, version information). Edit mode includes per-clock menu bar name controls.
3. `AppDelegate` — sets `.accessory` activation (no Dock icon), creates the `NSStatusItem` whose single-line title is `menuBarTitle` or whose two-line template image renders the shared name/time pairs, and shows/hides the `NSPopover` hosting `ClockPanel`. Left-click toggles the panel; right-click or Control-click opens a native Quit menu after closing the panel. Full-name live tooltips and accessibility labels cover all pinned clocks. A global mouse monitor closes the popover on clicks in other applications; the popover delegate installs it on show and removes it on close. Closing the popover or reopening resets the preview to live time.

## Data flow

`Timer` → `store.now` → `store.objectWillChange` → `AppDelegate.updateTitle()` (menu bar) and SwiftUI re-render (panel). All displayed times derive from `viewedDate`; the menu bar always uses live `now`.

## Decisions

- Sun/moon icon is a simple hour heuristic (07:00–18:59 = day in the clock's zone), not astronomical sunrise/sunset.
- The bundle is ad-hoc signed and not notarized — local build/distribution only.
- Default clocks: system zone (pinned), `Europe/London`, `America/New_York` (pinned) — only when nothing is saved.
